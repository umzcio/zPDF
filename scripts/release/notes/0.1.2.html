zPDF 0.1.2

New

  • Report a Bug / Send a Suggestion (Help menu): tell the zPDF team what went wrong without leaving the app — no GitHub account needed. You can see exactly what's sent. Your email (optional) stays private, screenshots are optional, and your PDFs, file names and document text are never sent.
  • Error messages now have a Report… button that fills in the error for you.

Fixed

  • Signing with a certificate still failed on some PDFs (for example, files made by web-to-PDF converters such as wkhtmltopdf). Signing and certificate encryption now work on them.
  • Unexpected engine errors now include a short technical detail, so reports can be diagnosed quickly.

Install or update

  • Already installed: choose zPDF ▸ Check for Updates….
  • New install: download zPDF-0.1.2.dmg, open it, and drag zPDF to Applications.

Requires macOS 15 or later on an Apple silicon Mac.
