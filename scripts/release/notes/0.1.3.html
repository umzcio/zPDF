zPDF 0.1.3

New

  • Bring Forward / Send Backward (Edit panel): move an object one step up or down past the object it overlaps, alongside Bring to Front / Send to Back.
  • Distribute Horizontally / Vertically: space three or more selected objects evenly.
  • Barcodes stay current: barcode fields regenerate automatically when you save, so they always match the form data.
  • Better automatic tagging on forms: numbered and bulleted lists on forms (side-by-side columns, spaced-out options) are tagged as proper lists, and stray numbered labels are no longer tagged as one-item lists.

Fixed

  • Hundreds of damaged or unusual real-world PDFs no longer cause “unexpected error” failures. Edits now either work or explain that part of the file is damaged — the document can still be viewed and printed.
  • PDFs with a malformed comment or annotation are no longer opened read-only.
  • Fonts with non-English names no longer break Reduce File Size, PDF/A or the Fonts list.
  • A crafted image in a PDF can no longer make an edit hang for minutes.

Install or update

  • Already installed: choose zPDF ▸ Check for Updates….
  • New install: download zPDF-0.1.3.dmg, open it, and drag zPDF to Applications.

Requires macOS 15 or later on an Apple silicon Mac.
