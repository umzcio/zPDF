# zPDF 0.1.1

A fix release for testers of 0.1.0.

## Fixed

- **Signing with a certificate failed** ("The PDF engine could not complete
  this operation") on most PDFs exported from web browsers, Microsoft Office,
  Google Docs and design tools. Signing now works on those files, and so does
  encrypting a PDF for specific certificate recipients.
- **Better conversions to Word, Excel, PowerPoint, HTML, Markdown, RTF, XML
  and EPUB:**
  - Labels inside drawings are no longer mistaken for tables, which dropped
    or scrambled words.
  - Map scale bars stay with their map.
  - Paragraphs that continue into the next column are kept together.
  - Words hyphenated at a line break are joined back up in reading-order
    formats.

## Install or update

- **Already on 0.1.0:** choose **zPDF ▸ Check for Updates…**.
- **New install:** download `zPDF-0.1.1.dmg`, open it, and drag **zPDF** to
  **Applications**.

Requires macOS 15 or later on an Apple silicon Mac.
