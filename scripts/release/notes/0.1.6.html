zPDF 0.1.6

zPDF now has a Windows version with the same tools, and the Mac and Windows apps share version numbers from this release on (so this one skips 0.1.4 and 0.1.5).

Fixed

  • Comments on one page appeared on other pages in PDFs where several pages share one annotation list. Each page now gets its own before an edit.
  • Barcode fields were drawn mirrored. They now scan correctly.
  • Extract, Split and Delete Pages kept hidden references to the removed pages (form fields, bookmarks, links, tags), so a one-page extract could still carry the whole document. Removed pages are now really gone, and files are as small as they should be.
  • Split by File Size made parts about twice the chosen limit. Parts now fit.
  • Moving or scaling an image that sits inside a clipping frame cut it off at its old position. The frame now moves with it.
  • Replace Text made letters vanish when the document's font didn't include them. It now falls back to a font that has them.

Install or update

  • Already installed: choose zPDF ▸ Check for Updates….
  • New install: download zPDF-0.1.6.dmg, open it, and drag zPDF to Applications.

Requires macOS 15 or later on an Apple silicon Mac. For Windows, see the Windows release.
